# T2306 — Header + Dashboard Polish

## Веха

M23 — Frontend Polish

## Тип

code

## Проблема

Расхождения между прототипом и фронтендом в хеддере и Dashboard.

### Хеддер

1. **Аватар — зелёные буквы на зелёном фоне.** Невидимый текст. На зелёном может быть только белый.
2. **Аватар — лишний контент.** ФИО и роль рядом с аватаром — убрать, оставить только круг.
3. **«Детали льготы» в навигации.** Маршрут `/catalog/:slug` попадает в навигацию — убрать.
4. **Лого не на уровне контента.** Лого в header'е, а контент начинается ниже — нужно всё в «Стакане» (Container).
5. **«Баллы» вместо «Мои баллы».** В навигации и balance pill.

### Dashboard

1. **Дата без дня недели.** «31 мая 2026» вместо «Среда, 31 мая 2026».
2. **Размер цифр.** «Баланс» и «Активные льготы» — 16px, «До конца периода» — 26px. Нужно унифицировать.
3. **Нет иконок в заголовках секций.** «Активные льготы», «Быстрые действия», «Последние события» — без иконок.

## Что делать

### Хеддер

1. **Аватар — белые буквы:** `color: '#FFFFFF'` в Avatar style
2. **Аватар — только круг:** убрать Group, Text с ФИО и ролью из UserMenu
3. **Убрать «Детали льготы»:** удалить строку с `hidden: true` из employeeRoutes или добавить фильтр
4. **Лого в Container:** перенести лого из header в main content, на уровень greeting
5. **«Мои баллы»:** заменить label в employeeRoutes и текст в balance pill

### Dashboard

1. **Дата с днём недели:** добавить `weekday: 'long'` в toLocaleDateString
2. **Размер цифр:** `fontSize: suffix ? 26 : 26` → всегда 26px
3. **Иконки в заголовках:** добавить AprilIcon к каждому секционному заголовку
